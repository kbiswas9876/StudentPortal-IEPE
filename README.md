# Student Portal - IEPE

Student-facing web application for practice sessions, mock tests, revision hub with spaced repetition (SRS SM-2), and performance analytics.

## Tech Stack
- **Framework**: Next.js 15 (App Router)
- **UI & Styling**: Tailwind CSS, Framer Motion, Lucide & Heroicons
- **Math Rendering**: KaTeX
- **Database**: Supabase PostgreSQL
- **State Management**: React Context, Custom Hooks

## Features
- **Dashboard**: Practice setup, saved sessions, daily streak tracking
- **Mock Tests**: Live timer, real-time status updates, proctoring rules
- **Revision Hub**: Spaced Repetition System (SM-2), bookmarks management, custom notes & tags
- **Analytics**: Topic strength/weakness, speed breakdown, accuracy trends
